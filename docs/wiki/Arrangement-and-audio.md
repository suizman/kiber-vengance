# Arrangement and audio

## Build a song

In **Arrange → Arrangement**, each section assigns one clip per track and a repeat count. Add, rename, reorder with buttons/drag, multi-select, copy, paste, duplicate, delete and make fills. **Load to Compose** opens its five clips together.

The timeline provides zoom, markers, exact seeking, loop and punch-in boundaries. Tempo/meter maps persist in the project; playback and WAV share a musical clock. Changing meter remaps positions to preserve musical shape.

## Non-destructive regions

In **Audio & sampler**, import multiple files, record microphone input or add lanes. Permissions and physical input depend on the browser. Regions retain position, length, source offset, gain, fades, reverse, pitch, source BPM and rate-based warp.

Edit **Clip/Track effects** without replacing the source: filter, brightness, compression, saturation, distortion, chorus, delay and reverb, with individual bypass, reset and **Original/Processed** comparison. Treatment presets include Voice presence, Radio, Megaphone and Cyberpunk.

**Load Deck** sends edited audio to Deck A. **Resample Deck** turns a temporary deck buffer into a persistent region. Regions play with the arrangement and can extend its tail; Pause resumes at the corresponding source offset.

Warp changes playback speed and pitch together; it is not independent pitch-preserving time stretch.

## Prism Keys

Load a file as a **25-key** chromatic instrument. Set root, trim, tune, level, filter, attack/release, reverse, polyphony and **gate / one-shot / loop** mode. Mouse, multitouch, QWERTY and MIDI provide note feedback. Use Z/X or octave buttons when the sampler is armed.

The sample persists through IndexedDB/Package. Use **Record Take** to capture a sampler performance.

## Automation and MIDI Learn

Automation Lab stores master/track curves and LFO modulation routes. **MIDI Learn** binds incoming CC messages to targets. **Read** point editing is available; imported Touch/Latch/Write metadata is retained without claiming automation recording in those modes.
