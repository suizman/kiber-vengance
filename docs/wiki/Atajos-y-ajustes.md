# Atajos, ajustes y ayuda

## Teclado

| Acción | Atajo |
| --- | --- |
| Play/Stop; armar grabación | Space; R |
| Seleccionar pista | 1–5 |
| Octava cromática | A W S E D F T G Y H U J K |
| Batería | A S D F G H J |
| Paleta de comandos | Ctrl/Cmd + K |
| Export / Export As | Ctrl/Cmd + E / Ctrl/Cmd + Shift + E |
| Focus | Shift + F |
| Solo / Mute / Mutation | Shift + S / Shift + M / Shift + V |
| Compose / Arrange / Performance deck | Shift + G / Shift + A / Shift + P |
| Clip launcher / Mix | Shift + L / Shift + X |
| Nuevo / duplicar / cuantizar clip | Shift + N / Shift + D / Shift + Q |
| Selección múltiple | Shift + click o marquee |
| Seleccionar todo / copiar / pegar notas | Ctrl/Cmd + A / C / V |
| Mover selección / cambiar longitud | Flechas / Alt + flechas horizontales; Shift aumenta el paso |
| Borrar / Undo / Redo | Delete o Backspace / Ctrl/Cmd + Z / Ctrl/Cmd + Shift + Z |

Las teclas musicales actúan en el contexto correspondiente y no durante escritura en formularios. Las octavas se cambian con controles visibles; Prism Keys armado admite Z/X. El piano visual es multitouch y libera notas ante cancelación, pérdida de foco o página oculta.

## MIDI

Web MIDI necesita soporte y permiso. Graba note on/off, velocity y expresión por canal: pitch bend, presión de canal/polifónica y CC74. La batería sigue el mapeo GM habitual. MIDI Learn asigna CC a parámetros; el launcher usa notas 36–63 para celdas visibles.

## Apariencia y accesibilidad

Settings ofrece **Neon Circuit, Acid Terminal, Ember Drive, Scarlett Protocol y Studio Classic**, key glow, etiquetas de atajos, acento de control y reset. Las preferencias se comparten entre teclados y se guardan aparte del proyecto. Escritorio admite escala 80–120%, densidad y Focus; los racks recuerdan su plegado.

EN/ES cambia navegación, controles y ayuda; inglés es el idioma inicial. **Guide** recorre el estudio en siete pasos y **?** activa ayuda contextual. Los controles tienen foco visible, descripciones accesibles y soporte de reducción de movimiento. En pantallas pequeñas se usan los mismos cuatro espacios y transporte compacto; la edición detallada sigue optimizada para escritorio.
