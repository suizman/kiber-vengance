# Shortcuts, settings and help

## Keyboard

| Action | Shortcut |
| --- | --- |
| Play/Stop; arm recording | Space; R |
| Select track | 1–5 |
| Chromatic octave | A W S E D F T G Y H U J K |
| Drums | A S D F G H J |
| Command palette | Ctrl/Cmd + K |
| Export / Export As | Ctrl/Cmd + E / Ctrl/Cmd + Shift + E |
| Focus | Shift + F |
| Solo / Mute / Mutation | Shift + S / Shift + M / Shift + V |
| Compose / Arrange / Performance deck | Shift + G / Shift + A / Shift + P |
| Clip launcher / Mix | Shift + L / Shift + X |
| New / duplicate / quantize clip | Shift + N / Shift + D / Shift + Q |
| Multi-selection | Shift + click or marquee |
| Select all / copy / paste notes | Ctrl/Cmd + A / C / V |
| Move selection / resize | Arrows / Alt + horizontal arrows; Shift increases the step |
| Delete / Undo / Redo | Delete or Backspace / Ctrl/Cmd + Z / Ctrl/Cmd + Shift + Z |

Musical keys follow the active context and do not interfere with form inputs. Visible controls change octave; armed Prism Keys also supports Z/X. The visual keyboard supports multitouch and releases voices on cancellation, lost focus or hidden pages.

## MIDI

Web MIDI requires browser support and permission. Record note on/off, velocity and per-channel expression: pitch bend, channel/poly pressure and CC74. Drums follow the usual GM mapping. MIDI Learn maps CC to parameters; the launcher uses notes 36–63 for visible cells.

## Appearance and accessibility

Settings offers **Neon Circuit, Acid Terminal, Ember Drive, Scarlett Protocol and Studio Classic**, key glow, shortcut labels, control accent and reset. Preferences are shared across keyboards and stored separately from the project. Desktop supports 80–120% scale, density and Focus; racks remember collapsed state.

EN/ES changes navigation, controls and help; English is the default. **Guide** tours the studio in seven steps; **?** enables contextual help. Controls provide visible focus, accessible descriptions and reduced-motion support. Compact screens retain the same four workspaces and transport; detailed editing remains desktop-oriented.
